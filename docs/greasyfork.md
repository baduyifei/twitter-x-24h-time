# GreasyFork 发布文案

本文件保存 GreasyFork 上架时使用的中文描述文本，方便后续统一维护。GreasyFork 发布表单包含两个文本字段：

- **简短描述（Description）**：列表页和搜索结果里显示，建议 ≤ 100 字。
- **详细描述（正文）**：脚本主页正文，支持 Markdown。

---

## 简短描述

将 Twitter/X 网页版中文界面里的「上午/下午 H:MM」时间显示转换为 24 小时制。纯本地处理，不联网、不读取 Cookie、不上传任何数据。

---

## 详细描述

把 Twitter/X 网页版中文界面里所有 `上午/下午 H:MM` 的时间显示转换成 24 小时制，让你在浏览推文、通知、悬停时间提示时不用再在脑子里换算「下午 8:30 到底是几点」。

### 转换示例

| 原始显示 | 改写后 |
|---|---|
| 上午 12:05 | 00:05 |
| 上午 9:30 | 09:30 |
| 下午 1:20 | 13:20 |
| 下午 12:40 | 12:40 |
| 下午 8:30:15 | 20:30:15 |

### 特性

- 支持 `twitter.com` 与 `x.com` 两个域名
- 支持 Twitter/X 单页应用动态加载的内容（无限滚动、切换页面后自动生效）
- 支持带秒数的时间格式（如 `下午 8:30:15` → `20:30:15`）
- 正确处理 12 点 / 0 点边界（午夜 `上午 12:00` → `00:00`，正午 `下午 12:00` → `12:00`）
- 跳过输入框、`<script>`、`<style>` 等不应被修改的节点

### 隐私与安全

- 脚本权限声明为 `@grant none`，**没有任何特殊权限**
- 仅在浏览器本地遍历当前页面文本节点做字符串替换
- **不发起任何网络请求**，不读取 Cookie，不上传数据
- 不修改网页链接，不注入广告，不干扰其他脚本
- 源代码不到 90 行，可自行审计

### 使用方法

安装后无需任何配置，打开或刷新 Twitter/X 网页即可生效。

## 发布操作提示

1. **上传方式**：在 GreasyFork "发布新脚本" 页面，可以选择 "从外部 URL 安装"，或者直接把脚本源码贴到代码编辑框 —— GreasyFork 会自动从 `@name`、`@description`、`@version`、`@license` 元数据里读取信息。务必保留脚本里的 `@license MIT`，否则 GreasyFork 会标记为"无协议"，影响信任度。
2. **应用范围（Applies to）**：GreasyFork 会自动从 `@match` 解析出 `twitter.com` 和 `x.com`，无需手动填。
3. **分类**：可选 "Twitter" 或 "网络应用 (Web app)"。
4. **不要放推广 / 联盟链接**：GreasyFork 禁止。GitHub 源码链接没问题。
5. **同步源（Sync from URL）**：发布后在脚本设置里填 GitHub raw 链接作为同步源，以后每次在 GitHub 发新版时（`@version` 变化），GreasyFork 会自动同步。推荐：

   ```
   https://github.com/baduyifei/twitter-x-24h-time/raw/main/twitter-x-24h-time.user.js
   ```
