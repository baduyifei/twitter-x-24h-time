# 安全说明

## 权限

脚本使用以下元信息：

- `@match https://twitter.com/*`
- `@match https://x.com/*`
- `@grant none`

这意味着脚本只在 Twitter/X 网页上运行，并且不申请 Tampermonkey 的额外特权 API。

## 数据处理

脚本只读取页面中的文本节点，并把匹配 `上午/下午 H:MM` 的文本替换为 24 小时制。脚本不会：

- 发送网络请求
- 读取或上传 Cookie
- 读取浏览器历史
- 修改页面链接
- 插入广告或推广参数

## 建议

从 GitHub 或本地文件安装用户脚本时，建议先阅读脚本源码，确认它没有额外权限、远程加载代码或外部请求。
