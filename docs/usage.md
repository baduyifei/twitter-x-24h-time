# 使用说明

## 工作方式

Twitter/X 是单页应用，页面内容会随着滚动、切换页面和弹窗操作动态加载。本脚本会：

1. 在页面加载后扫描已有文本。
2. 匹配中文时间格式，例如 `上午 9:30` 或 `下午9:30`。
3. 按 24 小时制规则替换文本。
4. 监听新加载的页面内容并继续处理。

## 支持的时间格式

- `上午 H:MM`
- `上午H:MM`
- `下午 H:MM`
- `下午H:MM`
- `上午 H:MM:SS`
- `下午 H:MM:SS`

半角冒号和全角冒号都支持。

## 已知限制

- 仅处理中文 `上午/下午` 格式。
- 不处理图片、Canvas 或浏览器原生弹窗中的时间。
- 如果 Twitter/X 改为不把时间作为普通文本渲染，脚本需要更新。

## 隐私

脚本没有网络请求和外部依赖，只在本地页面中执行文本替换。
